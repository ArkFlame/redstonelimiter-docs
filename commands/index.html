Commands & permissions

The main command is /redstonelimiter. You can use the shorter /rl or /redstone aliases.

Command reference

CommandActionPermission / restriction
/rlShows overall scope statisticsredstonelimiter.stats
/rl blockBlock statistics and top active blocksredstonelimiter.stats
/rl subchunkSubchunk statisticsredstonelimiter.stats
/rl chunkChunk statistics and active chunksredstonelimiter.stats
/rl chunk <world> <chunk-x> <chunk-z>Open a specific chunk’s block statistics (in-game)redstonelimiter.stats
/rl region32×32-chunk region statisticsredstonelimiter.stats
/rl guiOpen the in-game control panelredstonelimiter.admin
/rl reloadReload settings after applying pending GUI editsredstonelimiter.reload
/rl notificationsToggle your block notificationsConfigured notification permission
/rl tp <world> <x> <y> <z>Teleport to a redstone problem location (player only)Player only
/rl visit <server> <world> <x> <y> <z>Cross-server travel if Redis/proxy support is configuredConfigured notification permission

/rl menu also works as a compatibility alias of /rl gui.

How the control panel works

Open /rl gui in game. The GUI shows active chunks and blocks, plus controls for whitelist, manual quarantine, presets, and limits.

CHUNK VIEW

Inspect a problem

Click a chunk to view its individual active blocks. Shift-left-click a chunk to toggle its whitelist policy. Shift-right-click to toggle manual quarantine.

LIMITS VIEW

Tune thresholds

Change enabled state, maximum activations, duration, sustain and sliding mode separately for each scope. Block Max opens a dedicated per-material limits page.

Quarantine is manual only. It does not happen automatically when redstone activity exceeds a configured max. Quarantine also takes precedence over whitelist. Watch the animated chunk-policy explanation →

Permission nodes

NodeDefaultPurpose
redstonelimiter.adminOPOpen and operate the control panel
redstonelimiter.statsOPView statistics
redstonelimiter.reloadOPReload plugin configuration
redstonelimiter.notifyOPReceive and toggle notifications (default configured node)

The notification permission is configurable via notifications.permission. Cross-server travel requires extra setup; it is disabled by default.
