START WITH THE BASICS

Three ideas. That's most of the config.

01

How many?

max-activations is how many activations to allow in the period. If the limit is 5, the sixth attempt is blocked.

02

Over how long?

duration-millis is the time window used for counting. 5000 milliseconds means 5 seconds.

03

How long blocked?

sustain-millis keeps an over-limit scope temporarily blocked. 2000 milliseconds means 2 seconds.

A REAL EXAMPLE

What does this YAML actually do?

This is a small excerpt of the current default config, not a made-up setting.

config.yml
blocks:
  enabled: true
  period:
    duration-millis: 5000
    sustain-millis: 2000
    sliding: true
  max-activations:
    DEFAULT: 5
    PISTON: 3
IN PLAIN ENGLISH

For each individual piston…

Count up to 3 recorded activations over the most recent 5 seconds before preset/TPS scaling. The next attempt is blocked, with a temporary 2-second sustain period. Continuing over-limit attempts can extend that block.

Other scopes may also block it. The effective limit can be higher when the preset or TPS scaling is more permissive.
