Limit calculator

See how many activations RedstoneLimiter allows before an over-limit attempt is blocked at a particular scope.

EFFECTIVE MAX ACTIVATIONS
6
The first 6 attempts fit the effective threshold; attempt 7 exceeds it.
ceil(3 × 1 × 2) = 6
What this calculator assumes: one scope and one activity period, no earlier sustained block, no other scope reaching its limit first, and an available TPS value unless you select otherwise. The plugin uses rolling or fixed window counters and may block sooner because of another scope.

The exact rule

The source uses ceil(base × presetMultiplier × tpsMultiplier), except that a base max of 0 means the threshold is unlimited. There is no “blocks after N milliseconds” setting here: the duration counts activity, while sustain defines how long an over-limit scope remains temporarily blocked.

Default TPS scaling

When enabled, 16.0 TPS or less results in a 1× multiplier; 19.5 TPS or higher results in 2×. Intermediate values interpolate linearly. If TPS cannot be measured or scaling is off, the multiplier is 1×.

For your own custom min-multiplier, max-multiplier, degraded-tps or healthy-tps values, this first calculator intentionally models the source defaults only.
