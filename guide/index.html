Getting started

From your first install to your first useful limits. No YAML experience required.

1. Install and open the config #

  1. Install the RedstoneLimiter plugin JAR in your server's plugins/ directory.
  2. Restart your Minecraft server so the plugin generates its files.
  3. Open plugins/RedstoneLimiter/config.yml with a text editor.
  4. Make a backup of your working configuration before experimenting.
Starting from an existing server? Don't replace a customized config with the default file. The plugin supports older configuration migration. Review your existing values before changing them.

2. Read your first limit #

config.yml
blocks:
  enabled: true
  period:
    duration-millis: 5000
    sustain-millis: 2000
    sliding: true
  max-activations:
    DEFAULT: 5
    PISTON: 3

This means the block limiter is active. An individual piston has a base limit of 3 attempts over the last 5 seconds. The next attempt exceeds its base threshold. Temporary blocking lasts at least 2 seconds and can be extended by further over-limit attempts. Presets and TPS scaling can raise the actual allowed count.

3. Decide what area to limit #

PRECISE

Block & subchunk

Useful when one specific device or a compact machine is excessively active.

BROADER

Chunk & region

Catch many devices adding up; affects wider areas and can block unrelated machinery.

A region here means 32×32 chunks (512×512 blocks horizontally), not one chunk or a Folia scheduler region. By default, the configured region limit is only 96 base activations over 5 seconds across the entire region. Read the spatial guide before tightening it.

4. Choose a preset #

PresetBase multiplierEffect
STRICT1×Uses your configured limit without preset relaxation.
BALANCED1.5×Raises allowed activations by 50% before rounding and TPS adjustment.
LENIENT2×Doubles the configured limit before TPS adjustment.
Important: TPS scaling is separately enabled by default. At healthy TPS, it may double allowed activations again. A base limit of 3 can therefore allow 6 activations under the STRICT preset at healthy TPS. Try the calculator.

5. Apply your changes and inspect problems #

  1. Save config.yml with valid YAML indentation (spaces, not tabs).
  2. Run /rl reload if you have redstonelimiter.reload.
  3. Use /rl gui to inspect the in-game control panel, or /rl chunk to see statistics.
  4. Watch blocked-activity notifications if you have redstonelimiter.notify.

The GUI offers chunk whitelist and manual quarantine controls. Never assume a machine is automatically permanently quarantined because it exceeded an activity threshold.
